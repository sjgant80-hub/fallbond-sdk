# fallbond-sdk

**FallBond · the two-agent bonding ceremony · sovereign · runs in your browser** — sovereign SDK extracted from `fallbond/index.html`.

## Install
```bash
npm install @ai-native-solutions/fallbond-sdk
```

## Use
```js
import * as fallbond from '@ai-native-solutions/fallbond-sdk';
```
